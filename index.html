一条流水线，九个阶段

从客户进线到负责人触达，全程自动化；每个阶段都对应 n8n 里的一个节点

01

Webhook 统一接收

表单、邮件、企微、电话、小程序五个入口，收拢为一条流水线。

02

LLM 需求分析

识别意图、情绪、紧急度，让客户的声音变成可处理的数据（温度 0.1）。

03

AI 智能分类

7 类业务自动归口：售前 / 售后 / 技术 / 账单 / 合作 / 投诉 / 其他。

04

知识库检索（RAG）

检索政策片段，让摘要与回复有依据、口径统一、不靠个人记忆。

05

自动生成摘要

≤60 字，引用知识库，负责人扫一眼就知道要不要处理（温度 0.4）。

06

生成结构化工单

工单号、客户、分类、情绪、紧急度、摘要全部结构化，可统计可复盘。

07

SLA 矩阵定级

7 分类 × 4 紧急度 = 28 组合，算出 P1~P4 时限与责任团队。

08

同步飞书 / 数据库

工单一键写入多维表格，全员看到同一份看板，含 SLA 字段。

09

通知负责人

飞书卡片带 [SLA 等级]，高危工单秒级触达，出错自动告警管理员。

业务价值：从「人工分拣」到「分钟级闭环」

200 人 SaaS 公司每天从 5 个入口收到上百条客户进线——改造前后对比

改造前

  • 客服早上开 5 个后台翻消息，漏看是常态
  • 凭经验分类，新员工常错派，客户被"踢皮球"
  • 手动复制粘贴进 Excel，字段混乱、无法统计
  • 答案靠个人记忆，口径不一
  • 夜间 / 周末无人响应，投诉发酵到社交平台

改造后

  • 全渠道进线统一接入，进线 0 等待
  • AI 识别意图 / 情绪 / 紧急度，自动归口 7 类业务
  • RAG 检索政策、摘要引用依据，口径统一
  • SLA 矩阵自动定级定责，P1 工单 30 分钟触达
  • 飞书卡片 @ 负责人 + 出错自动告警，投诉不隔夜

技术亮点

不是玩具 Demo——每一层都是企业级设计

RAG 知识库增强

进线 → 检索知识库 → 摘要引用政策片段。答案有依据、不编造，新人也能给出老员工水平的回复。

SLA 矩阵路由

7 分类 × 4 紧急度 = 28 组合 → P1~P4 时限 + 责任团队，通知卡片直接带 SLA 徽章，响应不再是拍脑袋。

错误处理与重试

独立 Error Workflow 出错即飞书告警管理员；关键写库 / 通知节点 retryOnFail，问题不过夜。

分温度双模型

分析 / 分类用 temperature 0.1 保证一致性，摘要用 0.4 更自然——同一套凭据，一个表达式切换。

国产模型适配

一套 OpenAI 兼容协议，MODEL_PROVIDER 环境变量切换 DeepSeek / 通义 / 智谱 / Kimi，国内直连。

国内一键部署

docker-compose 一键起 n8n + 自动导入工作流，镜像加速、npm 国内源、飞书原生集成，无需海外网络。
